# Scroll Animation Prompt – Information Systems Quote

## Quote
**Turning Ideas Into Efficient Systems**

## Objective
After Services section, create a scroll-based subtitle animation for the quote **“Turning Ideas Into Efficient Systems”** with a clean, modern, and professional Information Systems portfolio aesthetic.

## Animation Behavior
- Display the quote as a centered subtitle or hero text section.
- As the user scrolls, each word should progressively highlight based on scroll progress.
- Start with all words in a muted, low-opacity style.
- Smoothly transition the active word into a brighter accent color with full opacity.
- Highlight order should follow:

Turning → Ideas → Into → Efficient → Systems

- Previously highlighted words should remain slightly emphasized while the next word animates.
- Add smooth easing and subtle transitions using:
  - opacity
  - color transitions
  - subtle scale animation
  - optional soft glow effect

## Scroll Interaction
- Pin or make the section sticky while the animation is playing.
- Keep the subtitle visible during scroll progression.
- Synchronize the word highlighting smoothly with user scroll movement.
- After the final word is highlighted, allow a smooth transition into the next section.

## Visual Design Requirements
- Minimal and premium portfolio feel
- Clean typography suitable for an Information Systems portfolio
- Smooth and responsive behavior across desktop and mobile
- Include a subtle animated line or progress indicator beneath or beside the quote that grows based on scroll progress

## Technical Requirements
- Use smooth scroll-triggered animation
- Implement sticky/pinned section behavior
- Ensure polished transitions and smooth performance
- Make animations feel modern, refined, and synchronized with scrolling

## Expected Experience
The interaction should feel cinematic, smooth, and professional — as if the quote is being revealed progressively while the user scrolls, with each word gaining emphasis in sequence to reinforce the message:

**“Turning Ideas Into Efficient Systems”**
